# Benchmark results

Store one directory per model/runtime run here. Keep raw logs out of Git unless they contain no secrets and are useful for reproducibility.

Recommended directory name:

```text
<model>-<runtime>-<YYYY-MM-DD>
```

Each run should include:

- `metadata.json` based on `metadata.template.json`
- `prompt.txt`
- `diff.patch`
- `tests.txt`
- `review.md`
